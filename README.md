# Awesome 榜单中文速查表

把 [sindresorhus/awesome](https://github.com/sindresorhus/awesome) 的 677 个精选资源列表整理成一张可搜索、可按分类筛选的中文表格。

在线查看：https://yaowenhu-pm.github.io/awesome-list-table/

## 它解决什么问题

原榜单是一份 800 多行的 README，26 个分类平铺罗列，其中 213 条只有项目名、连一句英文简介都没有。想找"有没有现成的 XX 资源合集"只能靠 Ctrl+F 猜关键词，猜不中就翻不到。

这张表给每一条补了两列中文说明——内容是什么、有什么用——并支持全字段搜索，用中文关键词也能命中。

## 功能

- 四列表格：项目名（点击直达原仓库）、分类、内容是什么、有什么用
- 搜索框全字段模糊匹配，命中处高亮；按 `/` 快速聚焦
- 26 个分类 chip 带条目数，单击筛选
- 窄屏自动切换为卡片布局

## 文件结构

| 文件 | 说明 |
|---|---|
| `index.html` | 页面全部结构、样式与交互逻辑，无外部依赖 |
| `data.js` | 677 条数据，字段 `n` 名称 / `u` 链接 / `c` 分类 / `g` 子分组 / `d` 内容 / `s` 用途 |

改文案直接编辑 `data.js`；本地看效果双击 `index.html` 即可，不需要起服务。

## 数据来源与准确性

数据抓取自 awesome 仓库 `readme.md`（2026-08-07 快照）。项目名、链接、分类均为原文，未做改动。

中文的"内容是什么/有什么用"两列是补写的解读：其中 464 条有官方英文一句话简介，据其翻译改写；剩余 213 条原榜单没有任何描述，按项目名和仓库名推断。绝大多数条目是 `awesome-xxx` 这类自解释命名，判断风险不大，但它不是官方原文。当筛选线索用，真要选型还请点进原仓库确认。

## 更新数据

重新抓取 awesome 的 readme.md 后，按 `- [名称](链接) - 英文简介` 的格式解析（注意有 81 条是 Tab 缩进的二级子条目，父级可能是纯文本如 Linux、macOS），补写中文两列，再按 `data.js` 的字段名生成即可。
